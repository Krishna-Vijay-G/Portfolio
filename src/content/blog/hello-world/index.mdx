I already have a portfolio. It boots like a terminal, glitches an anagram across the screen, and has more moving parts than some products I have shipped. I like it. But every time I wanted to write something down, the machinery got in the way — and a site you never update is just a business card with extra steps.

So this is the other one. Powered by Astro, it ships HTML, CSS and barely any JavaScript, and it exists for two reasons: a place to write, and a place that still looks right when I have not touched it in six months.

Everything you would expect is on the [home page](/) — projects, experience, education, certifications, and a form that actually reaches me. This blog is where the rest goes: notes on interfaces, models, the odd IoT board, and whatever else I am learning at the time.

```ts
const site = {
  name: "Krishna Vijay G",
  alias: "Arkhins", // an anagram of Krishna
}
```

The code is open source, based on the excellent [amruthpillai.com](https://github.com/amruthpillai/amruthpillai) template. If you have feedback, the [contact form](/#contact) is right there.
